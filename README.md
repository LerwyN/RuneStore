# Rune

**Your Gateway to the World of Games.**

Rune is a digital game marketplace platform designed to bring players, games, and gaming communities together in one place.

Inspired by modern digital game distribution platforms, Rune aims to provide a clean, intuitive, and user-friendly gaming experience.

## About the Project

Rune is an independent game marketplace project developed under **Vault Games**.

The platform focuses on creating a digital ecosystem where users can discover games, explore their libraries, manage their accounts, and stay up to date with the latest gaming news.

## Features

- **Game Store** – Discover and explore games.
- **Game Library** – Manage your game collection.
- **Shopping Cart** – Add games to your cart.
- **Wishlist** – Save games for later.
- **User Accounts** – Register and manage your profile.
- **Admin Panel** – Manage games and store content.
- **Game Categories** – Browse games by genre.
- **News & Updates** – Stay informed about the platform.

## Technologies

- C#
- ASP.NET Core MVC
- Entity Framework Core
- PostgreSQL
- HTML5
- CSS3
- JavaScript

## Project Structure

Rune is being developed with a modular architecture, focusing on maintainability, scalability, and clean code principles.

## Development Status

Rune is currently under active development. New features, improvements, and updates are being introduced as the project evolves.
